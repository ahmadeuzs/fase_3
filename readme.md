| Perintah | Fungsi |
|---|---|
| `git branch` | Melihat branch |
| `git branch nama` | Membuat branch |
| `git switch nama` | Pindah branch |
| `git switch -c nama` | Buat + pindah branch |
| `git merge nama` | Menggabungkan branch |
| `git status` | Melihat kondisi repository |
| `git log --oneline` | Melihat history |
| `git log --oneline --graph --all` | Melihat history bercabang |
| `git add file` | Menandai perubahan siap commit |
| `git commit` | Membuat commit |
| `git diff` | Melihat perubahan |
